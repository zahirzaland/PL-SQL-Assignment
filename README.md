# PL/SQL Assignment

This repository contains a set of PL/SQL example programs extracted from `plsql.txt`.
Each example is saved as a separate `.sql` file with a filename that matches the task name.

## Included Programs

1. `01_Rectangle_Area_Program.sql` - Rectangle Area Program
2. `02_Find_Average_of_Three_Numbers.sql` - Find Average of Three Numbers
3. `03_Square_Area_Program.sql` - Square Area Program
4. `04_Find_Largest_Number_among_Three_Numbers.sql` - Find Largest Number among Three Numbers
5. `05_Find_Smallest_Number_among_Three_Numbers.sql` - Find Smallest Number among Three Numbers
6. `06_Even_and_Odd_Number_Program.sql` - Even and Odd Number Program
7. `07_Simple_Calculator_Program.sql` - Simple Calculator Program
8. `08_Celsius_to_Fahrenheit_Conversion.sql` - Celsius to Fahrenheit Conversion
9. `09_Student_Grade_Calculation_Program.sql` - Student Grade Calculation Program
10. `10_Find_the_Sum_of_Numbers_from_1_to_100.sql` - Sum of Numbers from 1 to 100
11. `11_Find_the_Factorial_of_a_Number.sql` - Factorial of a Number
12. `12_Electricity_Bill_Calculation_Program.sql` - Electricity Bill Calculation Program

## How to Use

1. Open the `.sql` file you want to run in your PL/SQL editor or SQL*Plus environment.
2. Execute the code block.
3. If using SQL*Plus, make sure `SET SERVEROUTPUT ON` is enabled to display `DBMS_OUTPUT.PUT_LINE` results.
